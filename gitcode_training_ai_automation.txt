===============================================================================
                       GIT & GITHUB CHEAT SHEET / REFERENCE GUIDE
===============================================================================
UPDATING THE FILE 
-------------------------------------------------------------------------------
1. INITIAL CONFIGURATION
-------------------------------------------------------------------------------
Set up your global identity and default branch name (run once on your machine):

  git config --global user.name "Your Name"
  git config --global user.email "your.email@example.com"
  git config --global init.defaultBranch main

Verify configuration:
  git config --list


-------------------------------------------------------------------------------
2. CREATING & STARTING REPOSITORIES
-------------------------------------------------------------------------------
Initialize a new local repository in current folder:
  git init

Clone an existing remote repository:
  git clone <repository-url>


-------------------------------------------------------------------------------
3. THE BASIC WORKFLOW (STAGING & COMMITTING)
-------------------------------------------------------------------------------
Check the state of your working directory and staging area:
  git status

Stage a specific file for the next commit:
  git add <filename>

Stage all modified and new files:
  git add .

Unstage a file while keeping changes in your working directory:
  git restore --staged <filename>

Commit staged changes with a message:
  git commit -m "Add descriptive message here"

Combine staging all tracked files and committing into one step:
  git commit -am "Commit message for tracked files"


-------------------------------------------------------------------------------
4. VIEWING HISTORY & DIFFERENCES
-------------------------------------------------------------------------------
View commit history (compact, 1-line view):
  git log --oneline

View commit history with visual branch structure:
  git log --oneline --graph --all

View unstaged changes in working directory:
  git diff

View staged changes ready for commit:
  git diff --staged


-------------------------------------------------------------------------------
5. WORKING WITH BRANCHES
-------------------------------------------------------------------------------
List all local branches:
  git branch

Create a new branch:
  git branch <branch-name>

Switch to a specific branch:
  git switch <branch-name>

Create and switch to a new branch in one step:
  git switch -c <branch-name>

Merge a branch into your current active branch (e.g., from main):
  git merge <branch-name>

Delete a branch (safe delete, prevents losing unmerged changes):
  git branch -d <branch-name>


-------------------------------------------------------------------------------
6. WORKING WITH REMOTES (GITHUB / GITLAB)
-------------------------------------------------------------------------------
Link a local repository to a remote repository:
  git remote add origin <repository-url>

View remote URLs:
  git remote -v
